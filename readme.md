# 空卡 · 空卡考研

「空卡」是一个面向 **2028 考研人**的资源导航站。

站名取的是「把一张空白的卡，一点点填成上岸」的意思：备考开始时手里往往只有一张空白的答题卡，课程、笔记、阶段资料要一样样自己找齐。空卡想做的，就是让「找资料」这件事少花点时间。

## 为什么有这个站

考研资料最烦的不是少，而是散——链接在群聊里、笔记在网盘里、更新在公告里，过几天再想找就得从头翻一遍。

空卡把这些入口收在**同一个页面**：三个板块、三个链接，点开就是对应的在线文档，新页面打开，看完关掉就回到这一页。不绕路、不用记网址，也不用反复问人「最新那份在哪」。

## 页面里有什么

**考研课程目录**
整份课程的总索引。公共课、专业课、各阶段课程都归在这一份目录里，按科目查找即可。覆盖英语、数学、政治、管理类联考、专业课，以及笔试、冲刺、押题、复试等方向。

**免费笔记网盘群**
免费领取笔记和资料的入口。笔记持续补档、群里同步更新，按页面指引进群即可，不需要转发、不需要付费。适合刚开始攒资料、不想从零整理的人。

**课程更新日志**
记录「什么时候上了什么课、补了哪些笔记、阶段资料到哪一步」。想确认资料有没有更新，翻一下日志就知道，不用在群里反复追问。具体日期与内容以在线文档为准。

## 内容覆盖

从公共课到专业课，从打基础的笔试阶段，到冲刺、押题、复试，九个方向都收在课程目录里。不同科目、不同阶段的人，进站后走的是同一条路：先看目录，再领笔记，之后跟着日志追更新。
